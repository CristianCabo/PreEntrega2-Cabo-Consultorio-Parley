🏥 Consultorio Parley — Sitio Web

Sitio web multi-página para un consultorio de Kinesiología, desarrollado como entrega del curso de Desarrollador Web en Coderhouse. Construido con HTML5, CSS3/SCSS y Bootstrap 5, con foco en diseño responsive y optimización SEO básica.

📋 Descripción

Landing institucional para un centro de kinesiología, con navegación entre distintas secciones: inicio, información del consultorio, staff profesional, especialidades ofrecidas y contacto. El proyecto combina experiencia real del área de salud con buenas prácticas de maquetado web.

✨ Funcionalidades
🧭 Navegación multi-página con navbar responsive (Bootstrap)
📱 Diseño adaptable a distintos tamaños de pantalla
🎨 Animaciones de entrada con Animate.css
🔍 Meta tags optimizadas para SEO (description, keywords)
🔗 Enlaces a redes sociales (Facebook, Instagram, Twitter, WhatsApp)
🖋️ Tipografías personalizadas vía Google Fonts (Freeman, Sedan SC)
🛠️ Tecnologías utilizadas
HTML5
CSS3 / SCSS
Bootstrap 5.3
Animate.css — animaciones de interfaz
Google Fonts

🚀 Cómo ejecutar el proyecto
Cloná el repositorio:
bash
   git clone https://github.com/CristianCabo/PreEntrega2-Cabo-Consultorio-Parley.git
Entrá a la carpeta del proyecto:
bash
   cd PreEntrega2-Cabo-Consultorio-Parley
Abrí index.html en tu navegador (recomendado usar la extensión Live Server de VS Code).

No requiere instalación de dependencias: es un sitio estático que corre completamente del lado del cliente.
